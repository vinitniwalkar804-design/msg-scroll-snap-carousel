# MSG Scroll Snap Carousel

A modern, responsive horizontal carousel built with native CSS scroll snap and Vanilla JavaScript. It combines smooth navigation, IntersectionObserver pagination, mouse drag with momentum, keyboard support, and a polished SaaS-style presentation — with no frameworks or build step.

## Features

- Native CSS scroll snap with smooth scrolling
- Exactly 10 feature cards with unique Remix Icons
- Responsive card sizing: ~1.2 / 2.5 / 3.5 cards visible
- Previous / next navigation with correct disabled states
- IntersectionObserver-powered pagination dots
- Mouse drag-to-scroll with subtle momentum
- Keyboard navigation (arrow keys, Home, End)
- Touch-friendly native scrolling
- Accessible labels, ARIA attributes, and visible focus states
- `prefers-reduced-motion` support
- Edge fade masks and next-card peek
- Works by opening `index.html` directly or via any static server

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript (no libraries or frameworks)

## CDN Dependencies

- Google Fonts — Plus Jakarta Sans: <https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&display=swap>
- Remix Icon 4.6.0: <https://cdn.jsdelivr.net/npm/remixicon@4.6.0/fonts/remixicon.css>

## Local Setup

1. Download or clone this repository.
2. Open `index.html` directly in a browser, or serve the folder:

   ```bash
   python -m http.server 8000
   ```

3. Visit <http://localhost:8000>.

No installation, package manager, or build command is required.
